# 주문 가능 근무지 선택

진입 경로: 대시보드 > pre-order > 캠페인 생성 또는 캠페인 수정 > Product 단계 > SKU의 주문 가능 근무지 셀

---

- 개별 SKU의 주문 가능 근무지를 설정하는 팝업이다.
- 선택 범위·기본값·Batch 변경 시 보존·주문 적용 기준은 [Product 및 Allocation 정책](../policy/Policy_04_Product_및_Allocation.md)을 따른다.
- 특정 근무지를 고르는 내부 팝업은 Timeline > Batch의 대상 근무지 선택에서 사용하는 공통 근무지 선택 흐름을 따른다. 이번 화면의 후보 제한과 0개 허용 기준은 아래와 같이 적용한다.

## 1. **주문 가능 근무지 팝업**

### 1-1. **헤더**

| 구분 | 정의 |
| --- | --- |
| Header | <ul><li>타이틀은 ‘주문 가능 근무지’다.</li><li>헤더에 닫기 [×] 버튼을 제공하지 않는다.</li></ul> |

### 1-2. **SKU 정보·근무지 설정 영역**

| 구분 | 정의 |
| --- | --- |
| Body | <ul><li>설정 대상 SKU의 상품명을 표시한다.</li><li>‘전체 근무지’·‘특정 근무지’를 단일 선택 옵션으로 제공한다.</li><li>각 옵션명 옆에 도움말 아이콘을 표시한다.</li><li>‘특정 근무지’를 선택하면 근무지 선택 필드를 표시한다.</li></ul> |

#### 1-2-1. **전체·특정 근무지 옵션과 도움말**

- 처음 열 때 해당 SKU에 적용된 설정을 표시한다. 신규 SKU의 기본값은 ‘전체 근무지’다.
- 옵션명 옆 도움말 아이콘에 마우스를 올리면 아래 문구를 툴팁으로 표시한다.

| 옵션 | 도움말 |
| --- | --- |
| 전체 근무지 | Batch의 모든 대상 근무지에서 주문할 수 있습니다. |
| 특정 근무지 | Batch의 모든 대상 근무지 중에서 선택한 특정 근무지에서만 주문할 수 있습니다. |

#### 1-2-2. **특정 근무지 선택 필드·초기화 버튼**

- ‘특정 근무지’ 선택 시 기존 공통 근무지 선택 필드를 제공한다.
- 선택한 근무지가 있으면 첫 번째 근무지명과 나머지 개수를 ‘근무지명 +N’ 형태로 표시한다. 한 개이면 근무지명만 표시한다.
- 필드를 선택하면 별도의 공통 근무지 선택 팝업을 연다. 뒤에 주문 가능 근무지 설정 팝업을 유지한다.
- 선택 초기화 버튼으로 선택 목록을 비울 수 있다. 목록을 비워도 설정 옵션은 ‘특정 근무지’를 유지한다.
- 0개 상태도 앞 설정 팝업의 [적용]으로 반영할 수 있다. 특정 근무지를 반드시 한 개 이상 선택해야 하는 기존 공통 설정 팝업의 검증을 그대로 적용하지 않는다.

| 케이스 | 조건 | 명세 |

| Case 1-3-1 | 설정 팝업에서 [적용] | <ul><li>선택한 옵션과 근무지 목록을 해당 SKU의 캠페인 편집값에 반영한다.</li><li>팝업을 닫고 Product 테이블의 요약값을 갱신한다.</li><li>특정 근무지 0개 또는 현재 Batch와 겹치는 근무지 0개도 적용할 수 있다.</li><li>실제 서버 저장은 기존 캠페인 저장 흐름을 따른다.</li></ul> |

## 2. **공통 근무지 선택 팝업**

### 2-1. **근무지 후보·선택 목록**

| 구분 | 정의 |
| --- | --- |
| Body | <ul><li>좌측에는 선택 후보, 우측에는 현재 선택한 근무지를 표시하는 기존 공통 양식을 사용한다.</li><li>좌측 후보는 해당 캠페인의 모든 Batch 대상 근무지를 합치고 중복 제거한 목록으로 제한한다.</li><li>기존 검색·필터·내 담당 근무지·전체 선택과 우측 선택 목록 검색·개별 해제·전체 해제 동작을 유지한다.</li><li>검색이나 필터로 조회 목록이 바뀌어도 기존 선택은 유지한다.</li></ul> |

- 후보 제한은 검색·필터·직접 추가 등 기존 선택 경로에도 동일하게 적용한다. Batch 대상 밖의 근무지를 새로 선택하는 경로를 만들지 않는다.
- Batch에서 제외되어 현재 후보에 없더라도 이전에 저장한 선택을 자동 제거하지 않는다. 공통 팝업에 전달하는 선택 목록과 적용 결과를 현재 후보 목록만으로 덮어쓰지 않는다.
- 후보 밖에 보존된 선택의 표시 방식은 공통 선택 목록 동작과 맞추되, 단순 조회·적용으로 보존된 선택이 유실되지 않도록 한다. 사용자가 직접 해제한 항목만 선택에서 제거한다.

### 2-2. **푸터의 취소·적용 버튼**

| 구분 | 정의 |
| --- | --- |
| Footer | <ul><li>기존 공통 팝업의 [취소]·[적용]을 사용한다.</li><li>선택 0개 또는 선택·필터 변경이 없는 경우의 [적용] 비활성화는 기존 공통 동작을 유지한다. 특정 0개 적용은 앞 설정 팝업의 선택 초기화로 처리한다.</li></ul> |

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 2-2-1 | 내부 팝업에서 [적용] | <ul><li>선택 결과를 앞 설정 팝업의 임시 선택값에 반영하고 내부 팝업을 닫는다.</li><li>앞 설정 팝업의 근무지명·개수 요약을 갱신한다.</li><li>이 단계에서 Product 테이블의 SKU 설정을 확정하지 않는다.</li></ul> |
| Case 2-2-2 | 내부 팝업에서 [취소]·닫기 | <ul><li>내부 팝업에서 변경한 내용을 반영하지 않고 앞 설정 팝업으로 돌아간다.</li></ul> |
