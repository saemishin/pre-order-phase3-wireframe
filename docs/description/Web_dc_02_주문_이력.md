# 주문 이력

진입 경로: 대시보드 > pre-order > 주문 조회 > 주문 상세 > 더보기 > [이력]

---

- 관리자 계열이 현재 주문의 이력을 조회하는 모달이다. 권한 범위는 [주문 이력 정책](../policy/Policy_07_주문_이력.md)의 적용·조회·보관 기준을 따른다. 앱에는 제공하지 않는다.
- 기록 대상·단위·이름 보존·시작 시점은 [주문 이력 정책](../policy/Policy_07_주문_이력.md)을 따른다.

## 1. **주문 이력 모달**

- 기존 주문 상세 모달 위에 중첩해 연다. 이력 모달의 너비와 높이는 주문 상세보다 작게 두어 뒤의 주문 상세가 보이도록 한다. 이력 모달이 열린 동안 뒤의 주문 상세는 조작할 수 없다.
- 단순 조회용 모달이다. [X] 또는 이력 모달 바깥 영역을 누르면 이력 모달만 닫고 기존 주문 상세로 돌아간다.

### 1-1. **헤더·닫기 버튼**

| 구분 | 정의 |
| --- | --- |
| Header | <ul><li>모달 타이틀과 [X]를 표시한다.</li></ul> |

### 1-2. **이력 목록**

| 구분 | 정의 |
| --- | --- |
| Body | <ul><li>현재 주문의 이력 목록을 표시한다.</li><li>기본 정렬은 최신순이다.</li></ul> |

- 검색·필터는 제공하지 않는다. 최신순으로 표시하며 같은 시각의 수정 항목은 주문 수정 화면의 항목 순서를 따른다.
- 별도 페이지 이동 버튼 없이 모달 내부 스크롤로 조회한다.

- 최초 조회에 실패하면 별도 오류 화면을 표시하지 않는다. 이력 모달을 닫고 기존 주문 상세를 유지하며 공통 오류 토스트를 표시한다.
- 토스트: **에러가 발생하였습니다. 잠시 후 다시 시도해보세요.** (`cm_error_tryagain`)
- 더보기 > [이력]으로 다시 진입하면 조회를 다시 요청한다. 조회 실패를 기록 0건으로 처리하지 않는다.
- 분할 조회 시 추가 조회에 실패해도 이력 모달을 열린 상태로 유지하고 이미 불러온 이력을 계속 표시한다.
- 문구 출처: [shopl_script · Script!F10613:G10613](https://docs.google.com/spreadsheets/d/1Uow3DrOkf0EGyUq8WNlg7SfFyIVfbCmJpD69ZfHZQZU/edit#gid=33333788&range=F10613:G10613).

### 1-3. **이력 카드**

- 정보 수정을 한 번에 여러 항목 저장해도 항목마다 독립된 카드로 표시한다. 프로덕트 그룹·SKU는 Case 1-3-2에 따라 하나의 주문 상품 변경 카드로 묶는다.
- 각 카드에 작업 처리 일시·수행자 이름·작업명 또는 수정 항목명을 표시한다.
- 항목명·수행자 이름·전후 값은 기록 당시 표시값을 사용한다.

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 1-3-1 | 정보 수정 | <ul><li>수정한 항목명과 변경 전·후 값을 각각 표시한다.</li><li>동일 저장의 여러 항목은 같은 수정자·수정일시를 가진 별도 카드로 표시한다.</li></ul> |
| Case 1-3-2 | 주문 상품 변경 | <ul><li>프로덕트 그룹과 SKU를 묶어 한 카드로 표시한다.</li><li>변경 전·후 각각에 그룹과 SKU를 함께 표시한다.</li></ul> |
| Case 1-3-3 | 주문 생성 | <ul><li>생성 작업 한 건에 작업명·주문 생성자·작업 처리 일시를 표시한다. 주문일시는 별도 항목으로 중복 표시하지 않는다.</li><li>최초 입력 항목별 전후 비교는 표시하지 않는다.</li></ul> |
| Case 1-3-4 | 최초 픽업·삭제·복구 | <ul><li>작업명·수행자·처리 시각을 표시한다.</li><li>작업에 따라 최초 저장되거나 복원된 값을 항목별 수정 카드로 나누지 않는다.</li></ul> |
| Case 1-3-5 | 인보이스 재생성 | <ul><li>성공한 재생성 작업과 수행자·처리 시각을 표시한다.</li><li>최초 인보이스 발행·실패 시도·열람·다운로드는 재생성 카드로 표시하지 않는다.</li></ul> |
| Case 1-3-6 | 첨부파일 추가·삭제 | <ul><li>해당 항목의 파일 추가·삭제 작업을 기존·변경 값으로 표시한다.</li><li>추가: 기존 없음 → 변경 추가한 파일. 삭제: 기존 삭제한 파일 → 변경 없음.</li><li>파일명만 텍스트로 표시하며 클릭 열람·다운로드는 제공하지 않는다.</li><li>파일 내용 비교나 사본 생성 기능을 추가하지 않는다.</li></ul> |

- 삭제·복구의 기록 기준은 유지하지만 이번 범위에 삭제된 주문 조회·복구 UI를 추가하지 않는다.
