## 3. **프로덕트 그룹 탭 영역**

- Product에서 설정한 그룹 하나당 탭 하나를 표시한다. 그룹명과 순서는 Product의 설정을 따르며 기존 캠페인은 저장된 순서를 사용한다.
- 최초 진입 시 첫 번째 그룹을 표시한다. 선택한 탭을 구분하며, 탭을 누르면 해당 그룹의 수량 설정 카드로 전환한다.
- 다른 그룹으로 이동해도 입력한 수량은 유지한다.
- 그룹명은 한 줄로 표시하고 긴 이름은 말줄임 처리한다. 해당 탭을 선택하면 카드 본문의 그룹명에서 전체 이름을 확인할 수 있다.
- 그룹 추가·이름 수정·삭제는 Product에서 관리한다. Allocation 탭에는 해당 조작 버튼을 제공하지 않는다.
- 탭 목록과 수량 표의 가로 스크롤은 각각 독립적으로 동작한다.

- 탭 변경 자체로 서버 저장하거나 입력값을 폐기하지 않는다.

### 3-1. **탭 좌우 이동 버튼**

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 3-1-1 | 모든 탭이 표시 영역 안에 들어옴 | <ul><li>좌우 이동 버튼을 표시하지 않는다.</li></ul> |
| Case 3-1-2 | 탭이 표시 영역을 넘침 | <ul><li>좌우 이동 버튼으로 탭 목록을 가로 이동한다.</li><li>목록 이동만으로 선택 그룹을 변경하지 않는다.</li><li>그룹 구성·이름·창 너비 변경에 따라 넘침 여부를 다시 판단한다.</li><li>검증 오류로 다른 그룹을 선택하면 해당 탭이 보이도록 이동한다.</li></ul> |

## 4. **그룹별 수량 설정 카드**

- 카드 상단 Product Group 레이블 아래에 선택한 그룹명을 표시한다.
- 선택한 그룹에 속한 SKU의 수량 표만 표시한다. 모든 그룹의 표를 아래로 이어 붙이지 않는다.

### 4-1. **유통사·SKU 수량 테이블**

- 기존 표 구성을 유지한다. 유통사는 행으로, SKU는 열로 표시하며 SKU별 상품명·코드 및 수량 합계를 제공한다.
- 수량 입력·합계 산출·숫자 형식 및 허용 범위 검증은 기존 기준을 유지한다.
- 캠페인 수정 시 주문 수량을 함께 표시하는 구성 등 기존 생성·수정 화면의 차이는 유지한다.
