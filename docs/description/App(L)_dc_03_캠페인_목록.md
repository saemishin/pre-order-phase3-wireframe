# 앱 캠페인 목록 · 리더 모드

진입 경로: Android 앱 > 리더 모드 > 메인 프리오더 카드 또는 메뉴 > Pre-order

---

- 일반 리더의 조회 허용(P04-A)과 리더의 진행 중 캠페인 표시(P08)를 반영한다. 기존 목록 구성을 유지한다.
- [권한 및 조회 범위 정책](../policy/Policy_02_권한_및_조회_범위.md)과 [캠페인 및 Batch 정책](../policy/Policy_03_캠페인_및_Batch.md#2-앱-리더-모드의-캠페인-상태-범위)을 함께 적용한다.

## 1. **상단 내비게이션**

- 기존 ‘Pre-order’ 타이틀과 뒤로 버튼을 유지한다.
- 뒤로 선택 시 기존 진입 경로에 따라 이전 화면으로 돌아간다.

## 2. **전체 개수·목록 영역**

### 2-1. **전체 개수**

- 기존 ‘전체 (N)’ 표시를 유지한다. N은 아래 역할·상태 조건을 충족하는 캠페인 수이며 주문 수가 아니다.
- 일반 리더의 담당 주문이 0건이어도 해당 캠페인을 개수에서 제외하지 않는다.

### 2-2. **조회 대상**

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 2-2-1 | 관리자 | <ul><li>진행 전·진행 중·종료 등 기존 조회 상태 범위를 유지한다.</li></ul> |
| Case 2-2-2 | 별도 pre-order 조회 권한 리더 | <ul><li>진행 중 캠페인만 표시한다.</li></ul> |
| Case 2-2-3 | 일반 리더 | <ul><li>캠페인 목록 조회를 허용하고 진행 중 캠페인만 표시한다.</li><li>담당 주문이 있는지를 추가 노출 조건으로 사용하지 않는다.</li></ul> |

- 기존 회사·삭제 여부·임시저장 작성자 조건을 유지한다. 임시저장 자체를 이유로 새 제외 조건을 추가하거나, 상태와 무관하게 항상 표시하는 예외를 추가하지 않는다.
- 기존 목록 정렬·추가 조회 방식을 유지한다. 상태 조건은 전체 개수 및 추가 조회에도 동일하게 적용한다. 받은 페이지에서 항목만 숨겨 전체 개수와 목록이 어긋나거나 조회 가능한 다음 항목을 놓치지 않도록 한다.

## 3. **캠페인 카드**

### 3-1. **상태·기간·캠페인명·이미지**

- 기존 상태 배지·기간, 캠페인명, 이미지 순서와 표시 형식을 유지한다.
- 카드 선택 시 해당 캠페인 상세로 이동한다. 역할별 주문 조회 범위를 상세에서도 동일하게 적용한다.
- 이미지 선택 시 기존 이미지 확대 동작을 유지하며 카드 상세 이동을 함께 실행하지 않는다.
- 이번 조회 확대를 이유로 기존 생성·편집·삭제 권한을 추가하지 않는다.

### 3-2. **Pre-order 수량·금액**

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 3-2-1 | 관리자·별도 pre-order 조회 권한 리더 | <ul><li>기존 회사 내 전체 주문 범위를 집계한다.</li></ul> |
| Case 3-2-2 | 일반 리더 | <ul><li>관리 그룹·하위 그룹 구성원의 조회 가능한 주문만 집계한다.</li><li>현재 소속, 퇴사·삭제 구성원, 일괄 등록 및 담당 범위 판정 불가 주문은 권한 정책을 따른다.</li></ul> |
| Case 3-2-3 | 조회 가능한 주문이 0건 | <ul><li>카드를 유지하고 수량·금액을 0으로 표시한다.</li><li>실제 주문 없음과 담당 범위 내 주문 없음을 구분해 안내하지 않는다.</li></ul> |

- 기존 숫자·금액 표시 형식을 유지한다. 카드 합계만 담당 범위 밖 전체 수치로 남기지 않는다.

### 3-3. **Batch 영역**

- 기존 Batch 개수와 펼침·접힘 동작을 유지한다.
- 펼치면 해당 캠페인의 Batch별 주문·픽업 기간 등 기존 정보를 표시한다. 일반 리더의 담당 주문 수에 따라 Batch 설정 정보를 줄이지 않는다.
- Batch 펼침·접힘 조작 시 캠페인 상세로 이동하지 않는다.
