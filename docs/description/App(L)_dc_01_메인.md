# 앱 메인 · 리더 모드

진입 경로: Android 앱 > 리더 모드 > 메인

---

- 일반 리더의 pre-order 조회 허용(P04-A)과 진행 중 캠페인 노출 기준(P08)을 반영한다. 직원 모드와 다른 홈 기능은 기존 동작을 유지한다.
- 역할·담당 구성원 판정은 [권한 및 조회 범위 정책](../policy/Policy_02_권한_및_조회_범위.md), 캠페인 상태는 [캠페인 및 Batch 정책](../policy/Policy_03_캠페인_및_Batch.md#2-앱-리더-모드의-캠페인-상태-범위)을 따른다.

## 1. **메인 헤더·메뉴 진입**

- 기존 메인 헤더와 메뉴·채팅·알림 구성을 유지한다.
- 회사의 pre-order 기능 사용을 전제로 일반 리더에게도 기존 pre-order 메뉴 진입을 허용한다. 관리자·별도 pre-order 조회 권한 리더의 기존 진입은 유지한다.
- 진행 중 캠페인이 없다는 이유로 메뉴 진입 자체를 숨기지 않는다.

## 2. **프리오더 카드 영역**

### 2-1. **카드 노출**

- 기존 홈 편집의 표시·숨김 및 카드 순서를 따른다.
- 관리자·별도 권한 리더·일반 리더 모두 기존처럼 진행 중 캠페인 하나를 표시한다. 여러 개이면 기존 등록일 최신순 기준으로 선택한다. 임시저장 캠페인은 기존 메인 조건에 따라 제외한다.

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 2-1-1 | 홈 표시 설정을 충족하고 진행 중 캠페인이 있음 | <ul><li>프리오더 카드를 표시한다.</li><li>조회 가능한 주문이 0건이어도 카드를 숨기지 않는다.</li></ul> |
| Case 2-1-2 | 진행 중 캠페인이 없음 | <ul><li>프리오더 카드 영역을 표시하지 않는다.</li><li>다른 홈 카드의 표시는 유지한다.</li></ul> |

- 기존 구현의 최신 20개 안에서만 진행 중 캠페인을 찾는 제약을 새 노출 정책으로 채택하지 않는다. 카드 대상 조회 시 위 조건을 충족하는 캠페인이 조회 한도 때문에 누락되지 않는지 확인한다.

### 2-2. **캠페인명·상태·기간·이미지**

- 기존 캠페인명, 상태 배지·기간, 이미지 순서와 표시 형식을 유지한다. 일반 리더의 담당 주문 유무로 캠페인 상태·기간을 바꾸지 않는다.
- 카드 선택 시 [캠페인 목록](App(L)_dc_03_캠페인_목록.md)으로 이동한다. 캠페인 상세로 바로 이동하지 않는다.
- 이미지 선택 시 기존 이미지 확대 동작을 유지하며 카드의 목록 이동을 함께 실행하지 않는다.

### 2-3. **Pre-order 수량·금액**

- 기존 숫자·금액 표시 형식을 유지한다.

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 2-3-1 | 관리자·별도 pre-order 조회 권한 리더 | <ul><li>기존 회사 내 전체 주문 범위로 집계한다.</li></ul> |
| Case 2-3-2 | 일반 리더 | <ul><li>관리 그룹·하위 그룹 구성원의 조회 가능한 주문으로 집계한다.</li><li>현재 소속, 퇴사·삭제 구성원, 일괄 등록 및 담당 범위 판정 불가 주문은 권한 정책을 동일하게 적용한다.</li></ul> |
| Case 2-3-3 | 조회 가능한 주문이 0건 | <ul><li>수량·금액은 0으로 표시한다.</li><li>실제 주문 없음과 담당 범위 내 주문 없음을 구분해 안내하지 않는다.</li></ul> |

- 메인 합계와 캠페인 목록·상세의 주문 조회 범위를 일치시킨다.

### 2-4. **Batch 영역**

- 기존 Batch 개수와 펼침·접힘 동작을 유지한다.
- 펼치면 Batch별 주문·픽업 기간 등 기존 정보를 표시한다. 담당 주문 범위에 맞춰 Batch 설정 정보를 줄이지 않는다.
- 펼침·접힘 조작 시 캠페인 목록으로 이동하지 않는다.

와이어프레임의 역할·데이터 상태 버튼과 가상 데이터는 검토용이다. 메인은 프리오더 영역만 발췌하며 다른 홈 카드는 그리지 않는다. 와이어프레임에서는 ‘프리오더 카드 비노출’ 설명을 표시한다. 실제 서비스에 추가하는 문구는 아니다. 실제 다른 홈 기능은 유지한다. 이미지 확대·기타 메뉴의 목업 생략은 기존 기능 제거를 의미하지 않는다. 메인 와이어프레임은 정상 조회 상태만 표현한다.
