# 앱 SKU별 지표 · 리더 모드

- [요약 및 일별 추이 정책](../policy/Policy_08_요약_및_일별_추이.md), [권한 및 조회 범위 정책](../policy/Policy_02_권한_및_조회_범위.md)을 따른다.

## 1. **상단 내비게이션·프로덕트 그룹명**

### 1-1. **뒤로 버튼**

- 내비게이션에는 제목 없이 뒤로 버튼을 제공한다.
- 뒤로 선택 시 캠페인 상세의 요약 화면으로 돌아간다. 요약의 지표별 펼침 상태와 기존 필터 조건을 유지한다.
- 이 화면에서 지표를 전환해도 복귀한 요약의 다른 지표를 자동으로 펼치지 않는다.

### 1-2. **프로덕트 그룹명**

- 본문 상단에 작은 `프로덕트 그룹` 라벨을 표시하고 그 아래 선택한 실제 프로덕트 그룹명을 표시한다.
- 요약에서 선택한 그룹과 조회 권한·필터 조건을 이어받는다. 이 화면에서는 다른 그룹을 선택하는 기능을 제공하지 않는다.
- 현재 적용된 필터는 상위 캠페인 상세에서 확인하거나 변경한다. 이 화면에는 상위 화면의 필터 조건을 그대로 적용한다.

## 2. **지표 선택**

- `Pre-order 수량`, `Pre-order 금액`, `픽업 수량` 세 지표를 제공한다. 최초 선택은 요약에서 해당 그룹에 진입할 때 선택한 지표다.
- 선택 필드를 누르면 앱의 단일 선택 하단 목록 팝업을 열고 현재 선택 항목에 체크를 표시한다. 추이 지표 선택과 동일한 앱 패턴을 사용한다.
- 항목 선택 시 적용하고 팝업을 닫는다. 바깥 영역 또는 뒤로로 닫으면 기존 선택을 유지한다.
- 지표 변경 시 프로덕트 그룹·조회 권한·기존 필터를 유지하고 총 합계와 모든 SKU 수치를 함께 변경한다. 서로 다른 조건의 합계와 SKU 수치가 섞이지 않도록 한다.
- 수량의 숫자 표기와 금액의 통화·자리 구분은 기존 앱 기준을 따른다.

## 3. **총 합계 카드**

- 라벨은 `총 합계`로 표시하고 그 아래 선택 지표의 합계 숫자를 표시한다.
- 선택 그룹의 현재 조회 대상 SKU별 수치를 합한 값이다. 상위 요약과 같은 권한·필터·기간을 적용하며 추이의 주간 합계로 해석하지 않는다.
- 대상 주문이 없으면 0으로 표시한다. 실제 주문 없음과 권한·필터 조건에 따른 0건을 구분하지 않는다.
- 관리자·별도 pre-order 조회 권한 리더는 기존 전체 범위, 일반 리더는 권한 정책에 따른 담당 구성원 범위로 집계한다. 담당 범위 밖의 수치를 추가로 보여주지 않는다.

## 4. **SKU 목록·카드**

### 4-1. **목록 제목·정렬**

- 목록 제목은 `SKU`로 표시한다.
- 선택 그룹에 속하면서 현재 필터의 상품 범위에 포함되는 SKU를 대시보드 설정 순서로 나열한다. 실적이 0이라는 이유로 항목을 제외하지 않는다.
- 항목이 많으면 화면의 세로 스크롤로 확인한다.

### 4-2. **제품명·SKU 코드·수치**

- 카드에 등록된 제품명(Product name), SKU 코드, 선택 지표의 수치 순서로 표시한다. 수치 오른쪽에 주문 목록 진입 꺾쇠를 둔다.
- 제품명은 색상·RAM·ROM을 별도 조합한 이름으로 대체하지 않는다. 같은 제품명도 SKU 코드로 구분할 수 있도록 코드를 함께 표시한다.
- 긴 제품명은 줄바꿈해 표시한다. 제품명·코드·큰 금액이 서로 겹치거나 잘리지 않도록 한다.

### 4-3. **주문 목록 진입·0건 표시**

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 4-3-1 | 조회할 주문 있음 | <ul><li>카드 선택 시 해당 SKU의 주문 목록으로 이동한다.</li><li>선택 SKU·지표와 조회 권한·기존 필터 조건을 전달한다.</li><li>주문 수량·금액은 대상 주문, 픽업 수량은 대상 픽업 완료 주문으로 연결한다.</li></ul> |
| Case 4-3-2 | 조회할 주문 0건 | <ul><li>카드와 0 수치를 유지한다.</li><li>꺾쇠만 연한 색으로 표시하고 카드 선택·주문 목록 진입을 막는다.</li><li>제품명·SKU 코드·수치는 흐리게 처리하지 않는다.</li></ul> |
| Case 4-3-3 | 금액은 0이나 대상 주문은 있음 | <ul><li>주문이 존재하므로 일반 꺾쇠를 표시하고 주문 목록에 진입할 수 있다.</li><li>금액 숫자만으로 진입 불가를 판단하지 않는다.</li></ul> |

- 같은 조회 조건을 주문 목록에도 적용해 상위 집계보다 넓은 범위의 주문을 제공하지 않는다.
