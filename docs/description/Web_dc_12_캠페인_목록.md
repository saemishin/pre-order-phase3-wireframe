# 캠페인 목록

진입 경로: 대시보드 > pre-order > 현황

---

- 일반 리더의 캠페인 조회 허용과 역할별 집계 범위(P04-A)를 반영한다. 기존 목록 구성과 이번에 변경하지 않는 동작은 유지한다.
- 역할과 담당 구성원 판정은 [권한 및 조회 범위 정책](../policy/Policy_02_권한_및_조회_범위.md)을 따른다. 조회 허용으로 캠페인 생성·수정·삭제 권한을 추가하지 않는다.

## 1. **상단 탭**

- 기존 ‘현황 → 통계 → 정보 및 안내 → 설정’ 순서를 유지한다.

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 1-1 | 관리자 | <ul><li>기존 현황·통계·정보 및 안내·설정 탭을 유지한다.</li></ul> |
| Case 1-2 | 별도 pre-order 조회 권한 리더 | <ul><li>현황·통계 탭을 제공한다.</li><li>관리자 전용 정보 및 안내·설정 탭은 노출하지 않는다.</li></ul> |
| Case 1-3 | 일반 리더 | <ul><li>현황·통계 탭을 제공한다.</li><li>정보 및 안내·설정 탭은 노출하지 않는다.</li></ul> |

- 통계 탭은 기존 외부 통계 대시보드로 연결한다. 해당 서비스가 페이지 진입 시 자체 접근 권한을 검증하는 기존 동작을 유지한다. 통계 탭 노출만으로 외부 서비스의 조회 권한을 부여하지 않는다.

## 2. **목록 상단 영역**

### 2-1. **전체 개수**

- 기존 ‘전체 N’ 표시를 유지한다. N은 주문 수가 아닌 조회 대상 캠페인 수다.
- 일반 리더의 조회 가능한 주문이 0건이어도 해당 캠페인을 목록과 전체 개수에서 제외하지 않는다.

### 2-2. **캠페인 생성 버튼**

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 2-2-1 | 관리자 또는 기존 캠페인 생성 권한이 있는 리더 | <ul><li>기존 생성 버튼 노출과 생성 화면 진입 동작을 유지한다.</li></ul> |
| Case 2-2-2 | 일반 리더 | <ul><li>캠페인 생성 버튼을 노출하지 않는다.</li></ul> |

## 3. **캠페인 목록 영역**

- 기존 캠페인 노출 조건·정렬·추가 조회 방식을 유지한다. 일반 리더도 기존 조건에 해당하는 캠페인을 조회한다.
- 앱 리더 모드의 ‘진행 중 캠페인만 표시’ 조건(P08)을 대시보드 목록에 적용하지 않는다. 임시저장 캠페인의 기존 작성자 기준도 유지한다.

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 3-1 | 조회 대상 캠페인이 있음 | <ul><li>기존 캠페인 카드 목록을 표시한다.</li><li>일반 리더의 담당 주문 유무를 캠페인의 추가 노출 조건으로 사용하지 않는다.</li></ul> |
| Case 3-2 | 조회 대상 캠페인이 없음 | <ul><li>전체 0건과 기존 빈 상태 화면을 표시한다.</li><li>문구는 ‘표시할 목록이 없습니다.’를 사용한다.</li></ul> |

- 로딩·추가 조회·조회 오류는 기존 처리를 유지한다. 조회 실패를 정상적인 캠페인 0건으로 처리하지 않는다.

## 4. **캠페인 카드**

### 4-1. **상태·기간·캠페인명·이미지**

- 기존 캠페인 상태, 기간, 이름 및 이미지 표시를 유지한다. 일반 리더의 담당 주문 수에 따라 캠페인 상태·기간을 변경하지 않는다.
- 카드 선택 시 해당 캠페인 상세로 이동한다. 일반 리더에게는 조회 전용 상세를 제공한다. 상세의 설정 정보와 수정 버튼은 [캠페인 상세 디스크립션](Web_dc_08_캠페인_상세.md#1-캠페인-설정-정보-영역)을 따른다.
- 임시저장 캠페인의 기존 편집 진입과 작업 권한은 유지한다.

### 4-2. **사전 주문 수량·금액**

- 기존 지표·숫자·금액 표시 형식을 유지하며, 역할별 조회 가능한 주문 범위에 맞춰 값을 집계한다.

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 4-2-1 | 관리자·별도 pre-order 조회 권한 리더 | <ul><li>기존 전체 주문 범위로 수량·금액을 표시한다.</li></ul> |
| Case 4-2-2 | 일반 리더 | <ul><li>관리 그룹·하위 그룹 구성원의 조회 가능한 주문만 수량·금액에 포함한다.</li><li>일괄 등록 주문과 구성원·소속 정보가 실제로 없어 담당 범위를 판정할 수 없는 주문은 제외한다.</li><li>구성원의 현재 소속을 적용하며, 퇴사·삭제 구성원도 남아 있는 소속 기준으로 조회를 유지한다.</li></ul> |
| Case 4-2-3 | 기존 기준상 아직 사전 주문이 시작되지 않음 | <ul><li>기존 ‘-’ 표시를 유지한다.</li></ul> |
| Case 4-2-4 | 사전 주문이 시작됐으나 조회 가능한 주문이 없음 | <ul><li>카드를 유지하고 수량·금액을 0으로 표시한다.</li><li>실제 주문이 없는 경우와 담당 범위 내 주문이 없는 경우를 구분해 안내하지 않는다.</li></ul> |

- 카드의 지표와 해당 캠페인 상세·주문 목록은 동일한 조회 권한 범위를 사용한다. 카드 합계만 담당 범위 밖 전체 주문 수치로 남기지 않는다.

### 4-3. **더보기·삭제 메뉴**

- 기존 관리자 대상 더보기·삭제 메뉴 노출과 삭제 확인 동작을 유지한다.
- 별도 pre-order 조회 권한 리더와 일반 리더에게 관리자 전용 삭제 메뉴를 노출하지 않는다.
- 메뉴 조작 시 카드 상세 이동을 함께 실행하지 않는다.

### 4-4. **Batch 영역**

- 기존 Batch 개수 및 펼침·접힘 동작을 유지한다.
- 펼치면 해당 캠페인의 Batch별 사전 주문·픽업 기간 등 기존 정보를 표시한다. 일반 리더의 담당 주문 수에 따라 Batch 설정 정보를 줄이지 않는다.
- Batch 펼침·접힘 조작 시 캠페인 상세로 이동하지 않는다.
