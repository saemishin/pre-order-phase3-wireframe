# pre-order 설정

진입 경로: 대시보드 > pre-order > 설정

---

- [권한 및 조회 범위 정책](../policy/Policy_02_권한_및_조회_범위.md)을 반영한다. 기존 캠페인 생성·전체 조회 권한 설정과 일반 리더의 담당 범위 조회를 구분한다.
- 기존 설정은 관리자 고정 선택, 리더 선택 여부, 전체·특정 리더 및 특정 리더 선택으로 구성된다. 조회에 사용되는 기존 권한 값이 캠페인 생성 버튼과도 연결돼 있으므로, 일반 리더 조회 허용을 위해 기존 지정값을 전체로 바꾸지 않는다.

## 1. **상단 탭·페이지 제목**

- 기존 현황·통계·정보 및 안내·설정 탭 구조와 관리자 설정 접근 권한을 유지한다.
- 페이지 제목은 기존 ‘Pre-Order 설정하기’를 유지한다.

## 2. **권한 설정 영역**

### 2-1. **설정 제목·안내**

- 제목은 기존 ‘캠페인 생성 및 조회 권한’을 유지한다.
- 안내: ‘관리자와 권한을 부여받은 리더는 캠페인을 생성하고 전체 주문을 조회할 수 있습니다. 권한이 없는 리더는 캠페인을 생성할 수 없으며, 자신이 관리하는 그룹과 하위 그룹 구성원이 등록한 주문만 조회할 수 있습니다.’
- 안내 문구의 ‘구성원이 등록한 주문’은 일반 리더의 관리 그룹·하위 그룹 구성원 범위에 해당하는 주문을 뜻한다. 일괄 등록 주문은 제외하며, 퇴사·삭제된 구성원의 기존 주문은 남아 있는 소속 기준으로 조회를 유지한다.
- 기존 리더 지정 대상의 생성 권한과 전체 조회를 유지하고, 지정되지 않은 일반 리더는 담당 범위를 조회하도록 구분한다. 별도의 ‘담당 범위 조회 허용’ 스위치를 새로 추가하지 않는다.
- 기존 생성 권한과 일반 리더의 담당 범위 조회를 구분해 적용한다. 안내 추가를 근거로 새로운 생성·수정 권한을 부여하지 않는다.

### 2-2. **관리자·리더 선택**

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 2-2-1 | 관리자 | <ul><li>기존과 같이 선택·비활성 상태로 고정한다.</li><li>기존 관리자 권한을 유지한다.</li></ul> |
| Case 2-2-2 | 리더 미선택 — NONE | <ul><li>별도 전체 조회 권한을 부여한 리더가 없는 것으로 해석한다.</li><li>일반 리더의 담당 범위 조회는 허용한다. pre-order 접근 자체를 금지한다는 뜻으로 표시하지 않는다.</li></ul> |
| Case 2-2-3 | 리더 선택 — ALL 또는 SPECIFIC | <ul><li>기존 전체 리더·특정 리더 옵션을 표시한다.</li><li>선택한 대상에게 기존 생성 권한과 전체 조회를 유지한다.</li></ul> |

### 2-3. **전체·특정 리더 및 대상 선택**

| 케이스 | 조건 | 명세 |
| --- | --- | --- |
| Case 2-3-1 | 전체 리더 | <ul><li>모든 리더를 별도 전체 조회 권한 대상으로 본다.</li></ul> |
| Case 2-3-2 | 특정 리더 | <ul><li>기존 리더 선택 팝업과 대상 표시를 유지한다.</li><li>선택한 리더는 전체 조회, 선택하지 않은 리더는 담당 구성원 범위 조회로 구분한다.</li></ul> |

- 리더 지정값과 대상 목록의 기존 저장값을 보존한다. 이 변경을 위해 전체 선택으로 일괄 전환하거나 대상 목록을 초기화하지 않는다.

## 3. **저장 버튼**

- 기존 변경 여부, 특정 리더를 선택하지 않은 경우의 저장 제한, 저장 후 갱신·안내를 유지한다.
- 일반 리더의 담당 범위 조회 판정과 캠페인 생성 판정을 분리해 적용한다. 단순히 기존 조회 허용 값을 모든 리더에게 true로 반환하여 생성 버튼까지 활성화되는 방식으로 연결하지 않는다.
