# P04-A 화면 반영 목록

화면 요소가 그대로여도 조회 데이터 조건이 달라지면 와이어프레임과 화면 디스크립션에 포함한다. 같은 화면의 역할·데이터 조건은 우측 케이스로 묶고, 기존 화면을 아이템별로 중복 작성하지 않는다.

| Web · pre-order 설정 | 기존 생성·조회 권한 설정을 전체 조회 대상과 일반 리더 담당 범위 조회로 구분. 기존 생성 권한 유지 | 리더 미선택 / 전체 / 특정 | 기존 설정 구성·제목과 역할별 안내 문구 검토 완료. 생성·전체 조회 권한과 일반 리더 담당 범위 조회의 구분을 [Web_dc_10](description/Web_dc_10_pre-order_설정.md)에 반영 |

[앱 주문 상세](description/App(L)_dc_06_주문_상세.md)에 화면 요소별 명세 작성. 기존 주문/고객 탭, 관리자 개인정보 3개 표시·두 리더 비노출, 기존 연결 기능·작업 권한 및 목록 왕복 유지 |

- 관리자와 별도 권한 리더는 전체 조회가 같더라도 생성·수정·개인정보 권한까지 같은 역할로 합치지 않는다.
- 직원 모드는 이번 조회 권한 확대의 대상이 아니다.
- 외부 통계 대시보드의 기존 통계 탭·링크는 일반 리더에게도 제공한다. 새미 확인에 따라 페이지 진입마다 외부 서비스 자체 접근 권한 검증을 유지하며, 이번 P04-A에서 외부 서비스의 권한 체계나 조회 범위를 변경하지 않는다.
- 직접 주소 접근의 기존 조사 내용은 기획 기록에 보존하되 별도 보안 감사나 이번 검토의 선행 과제로 확장하지 않는다. 정상 목록·상세·집계의 담당 범위 적용은 P04-A 본래 범위로 관리한다.
