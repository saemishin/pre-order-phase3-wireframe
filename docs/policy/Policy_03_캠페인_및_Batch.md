# 캠페인 및 Batch

## 1. 캠페인당 프로덕트 그룹 수

- 캠페인당 프로덕트 그룹을 최대 **20개**까지 등록할 수 있다.
- 신규 캠페인 생성과 기존 캠페인 수정에 동일한 상한을 적용한다. 기존 캠페인은 등록된 그룹을 유지하며 허용된 수정 범위 안에서 최대 20개까지 추가할 수 있다.
- 최대 개수에 도달하면 추가할 수 없다. 그룹 삭제 후 20개 미만이 되면 다시 추가할 수 있다.
- 상품을 업로드하지 않았거나 이름을 입력하지 않은 작성 중 그룹도 최대 20개 제한에 포함한다.
- 프로덕트 그룹 내 SKU 수와 업로드 용량은 현행을 유지한다. 그룹 수 확대를 이유로 그룹별 SKU 상한이나 파일 처리량을 변경하지 않는다.
- 캠페인의 생성·수정 권한과 상태별 수정 가능 범위는 기존 정책을 따른다.

## 2. 앱 리더 모드의 캠페인 상태 범위

- Android 리더 모드의 관리자·별도 pre-order 조회 권한 리더·일반 리더를 구분한다. 주문 조회 범위는 [권한 및 조회 범위 정책](Policy_02_권한_및_조회_범위.md)을 함께 적용한다.
- 진행 중은 회사 시간대의 오늘 날짜가 Timeline에 설정한 캠페인 시작일~종료일에 포함되는 상태다. 시작일과 종료일을 포함하며 Batch 주문·픽업 기간으로 새로 판정하지 않는다.
- 관리자 목록은 기존 상태 범위를 유지한다. 별도 권한 리더·일반 리더 목록은 기존 조회 조건에 진행 중 상태 조건을 적용한다.
- 목록의 기존 회사·삭제 여부·임시저장 작성자 조건은 유지한다. 임시저장 자체를 이유로 새 제외 조건을 추가하거나 상태와 무관하게 항상 조회하는 예외를 추가하지 않는다.
- 메인은 모든 역할에서 기존처럼 임시저장을 제외한 진행 중 캠페인을 대상으로 한다. 기존 홈 표시·숨김 설정을 유지한다.
- 담당 구성원 주문이 0건이라는 이유로 캠페인을 조회 대상에서 제외하지 않는다.
- 직원 모드의 캠페인·Batch 조회 조건은 이번 변경에 포함하지 않는다.
