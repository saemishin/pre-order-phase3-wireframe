# 권한 및 조회 범위

## 1. 역할별 pre-order 조회

- 회사의 pre-order 기능 사용을 전제로 한다. 앱은 Android의 리더 모드와 직원 모드를 구분한다.
- ‘별도 조회 권한 리더’는 기존 pre-order 권한 설정으로 전체 조회가 허용된 리더를 뜻한다. ‘일반 리더’는 이 별도 권한이 없는 리더를 뜻하며, 리더 모드 자체를 사용할 수 없는 사용자를 의미하지 않는다.

| 역할 | 대시보드 | 앱 |
| --- | --- | --- |
| 관리자 | 기존 전체 조회 유지 | 리더 모드에서 기존 전체 조회 유지 |
| 별도 pre-order 조회 권한 리더 | 전체 주문 조회 유지 | 리더 모드에서 전체 주문 조회 |
| 일반 리더 | 관리 그룹·하위 그룹 구성원의 주문 조회 허용(일괄 등록 제외) | 리더 모드에서 동일한 담당 구성원 범위의 주문 조회 허용 |
| 직원 | 이번 변경으로 대시보드 조회 권한을 추가하지 않음 | 직원 모드의 기존 동작 유지 |

- 전체 조회는 해당 회사 내 기존 조회 범위이며 다른 회사의 데이터 접근을 허용하지 않는다.
- 조회 권한의 확대와 캠페인 생성·수정, 명단 관리, 주문 수정·삭제·이력 조회 권한을 구분한다. 기존 작업 권한을 유지하며 일반 리더의 담당 범위 조회 허용만으로 작업 권한을 추가하지 않는다.
- 일반 리더에게는 캠페인 상세의 수정 버튼을 노출하지 않는다. 캠페인 설정 조회를 허용하더라도 수정 화면으로 진입할 수 없도록 한다.
- 관리자 계열의 주문 수정·삭제·이력 조회 기준은 기존 ADMIN·SUPER_ADMIN·OPERATOR 구분을 유지한다.

## 2. 일반 리더의 주문 범위

- 리더가 Shopl에서 관리하는 그룹 및 그 하위 그룹에 속한 구성원이 해당 주문의 판매 담당 구성원으로 기록된 주문을 조회한다. 단순히 리더 본인이 소속된 그룹을 조회 범위로 사용하지 않는다.
- 일괄 등록 주문은 일반 리더의 조회 대상에서 제외한다. 업로드 실행자의 소속이 리더의 관리 범위에 포함되어도 이 제외 기준을 우선 적용한다. 관리자·별도 pre-order 조회 권한 리더의 기존 전체 조회는 유지한다.
- 일괄 등록의 업로드 실행자가 등록자로 저장되는 기존 동작을 유지한다. 별도 판매 직원 지정·귀속 기능은 추가하지 않는다.
- 같은 근무지에서 등록된 주문이어도 판매 담당 구성원이 관리 대상이 아닌 주문은 제외한다.
- 별도의 ‘리더 본인의 담당 근무지’ 조건을 추가로 교차 적용하지 않는다. 담당 구성원의 주문 가능 근무지를 합친 뒤 그 근무지의 모든 주문을 보여주는 방식도 적용하지 않는다.
- 고객이 설명한 ‘매장별 Leader 1명·Manager 1명’은 조직 운영 배경이다. 이 정책으로 새로운 Manager 역할이나 매장 배정 상한을 만들지 않는다.
- 여러 관리 그룹의 포함 범위는 기존 관리 그룹·하위 그룹 산출 구조와 연결한다. Sales Target의 최상위 그룹 리더 예외를 별도 pre-order 전체 조회 권한으로 자동 치환하지 않는다.

## 3. 현재 소속 기준

- 조회 시점의 리더 관리 그룹·하위 그룹과 주문에 기록된 판매 담당 구성원의 현재 소속을 기준으로 판정한다. 주문 당시 소속을 고정해 사용하지 않는다.
- 구성원이 A 그룹에서 B 그룹으로 이동하면 이동 전에 판매 담당자로 기록된 주문도 현재 B 그룹 담당 리더의 조회 대상이 된다. A 그룹 담당 리더의 현재 관리 범위를 벗어나면 A 그룹 담당 리더에게는 보이지 않는다.
- 양쪽을 모두 관리하는 상위 리더 등 현재 관리 범위에 계속 포함되는 경우 조회를 유지한다.
- 구성원이 퇴사·삭제되어도 구성원 정보에 남아 있는 소속이 리더의 관리 그룹·하위 그룹에 포함되면 해당 구성원의 기존 주문 조회를 유지한다. 재직 여부만으로 주문을 제외하지 않는다. 일괄 등록 주문의 제외 기준은 동일하게 적용한다.
- 이 처리는 조회 범위를 바꾸는 것이며 주문 등록자·주문 근무지 등 기존 주문 정보를 변경하지 않는다. 담당 범위로 집계한 요약·차트 값도 소속 이동에 따라 달라질 수 있다.

## 4. 화면과 집계에 적용하는 기준

- 허용된 주문 범위를 주문 목록·주문 상세·요약·SKU별 지표·일별 추이에 일관되게 적용한다. 화면에 보이는 행만 줄이고 합계는 전체 주문 기준으로 남기는 방식으로 처리하지 않는다.
- 기존 검색·필터는 허용된 주문 범위 안에서 적용한다. 필터를 해제하거나 변경하는 동작으로 권한 범위를 넓히지 않는다.
- 필터의 종류·후보 목록·후보 조회 방식은 기존 동작을 유지한다. 일반 리더의 담당 구성원이나 조회 가능한 주문을 기준으로 후보 목록을 별도 축소하는 기능은 추가하지 않는다. 담당 범위 밖 근무지 등을 선택하더라도 허용된 주문 범위와 선택 조건을 함께 적용하며, 일치하는 주문이 없으면 기존 빈 상태를 표시한다.
- P08의 캠페인 상태 기준은 주문 조회 범위와 별도로 적용한다. 리더의 진행 중 캠페인 표시와 관리자의 기존 표시 기준을 이 정책만으로 변경하지 않는다.
- 일반 리더의 담당 구성원 주문이 0건이어도 캠페인을 숨기지 않는다. 기존 캠페인 노출 조건을 따르며 담당 주문 수를 캠페인 목록의 추가 제외 조건으로 사용하지 않는다. 주문 목록에는 기존 빈 상태를 적용한다.
- 실제 주문이 없는 경우와 사용자에게 조회 가능한 주문이 없는 경우는 동일한 빈 상태로 표시한다. 현재 사용자의 조회 범위에서 전체 0건으로 표시하며, 권한 범위 밖 주문의 존재를 별도로 안내하지 않는다. 조회 실패는 정상적인 0건과 구분하여 기존 오류 처리를 따른다.
- 일반 리더에게 캠페인 설정 정보를 제공하며 대상 근무지·구성원의 기존 요약 표시도 유지한다. 대상 전체 목록 진입은 추가하지 않고 구성원 프로필의 기존 공통 조회 권한을 유지한다. 설정 정보 공유와 담당 범위 밖 주문·실적 조회는 구분한다.
- 일괄 등록 주문 제외와 퇴사·삭제 구성원의 소속 기준은 주문 목록·상세·요약·SKU별 지표·일별 추이·다운로드에 동일하게 적용한다.
- 구성원 또는 소속 정보가 실제로 존재하지 않아 담당 범위를 판정할 수 없는 주문은 일반 리더의 조회 대상에서 제외한다. 근무지·다른 구성원 등으로 임의 귀속하지 않는다. 관리자·별도 pre-order 조회 권한 리더는 기존 전체 조회 범위를 유지한다. 이 기준은 주문 목록·상세·요약·SKU별 지표·일별 추이·다운로드에 동일하게 적용하며, 주문 데이터 자체를 삭제하는 것은 아니다.

- 주문 수량·금액의 실적 비율에서 분모인 배정 수량·금액은 기존 기준을 유지한다. 일반 리더의 담당 구성원 범위에 맞춰 배정값을 새로 배분하거나 축소하지 않는다. 주문 실적은 허용된 주문 범위와 기존 검색·필터 조건을 적용한다.
- 픽업 실적 비율은 같은 조회 범위와 검색·필터 조건에 해당하는 오프라인 주문 수량을 분모로 사용한다.

## 5. 고객 정보 표시와의 관계

조회할 수 있는 주문의 범위(P04-A)와 해당 주문에서 표시할 고객 정보(P04)는 별개로 적용한다. 아래 세 항목은 전화번호·이메일 주소·신분증 번호다.

| 역할 | 대시보드의 세 항목 | 앱 리더 모드의 세 항목 |
| --- | --- | --- |
| 관리자 | 표시 유지 | 표시 유지 |
| 별도 pre-order 조회 권한 리더 | 표시 유지 | 비노출 |
| 일반 리더 | 비노출 | 비노출 |

- 이름 등 나머지 주문·고객 정보는 별도로 숨기기로 한 항목이 없다면 기존 표시를 유지한다. 직원 모드의 표시도 현행을 유지한다.
- 개인정보 표시 동작은 [웹 주문 상세](../description/Web_dc_01_주문_상세.md)와 [앱 주문 상세](../description/App(L)_dc_06_주문_상세.md)를 따른다. 인보이스·첨부파일 등 연결 기능을 이 정책으로 일괄 제거하거나 추가 허용하지 않는다.

## 6. 대시보드 주문 목록 다운로드

- 일반 리더도 기존 다운로드 기능을 사용한다. 다운로드 대상은 화면과 동일한 담당 구성원 주문 범위에 검색·필터 조건을 적용한 주문이다. 현재 페이지에 표시된 행만으로 제한하는 의미는 아니다.
- 다운로드 파일에서도 일반 리더에게 고객 전화번호·이메일 주소·신분증 번호를 제공하지 않는다. 전화번호에 결합된 국가번호도 함께 제외한다.
- 관리자·별도 pre-order 조회 권한 리더는 대시보드의 기존 주문 조회 범위와 개인정보 제공 기준을 유지한다.
- 기존 다운로드 파일은 화면의 목록 표보다 많은 정보를 포함한다. 이번 변경은 주문 조회 범위와 개인정보 비노출 기준을 맞추는 것이며, 파일을 화면의 표 컬럼만으로 재구성하는 것은 아니다.
- 일반 리더용 다운로드 파일에서는 고객 전화번호·이메일 주소·신분증 번호의 세 열 자체를 제외한다. 해당 열의 헤더와 데이터를 모두 생성하지 않으며, 빈 열이나 숨김 열로 남기지 않는다. 나머지 항목은 기존 양식을 유지한다.

## 7. 외부 통계 대시보드 진입

- 일반 리더에게도 기존 통계 탭과 외부 통계 대시보드 링크를 제공한다. 별도 pre-order 조회 권한 유무로 통계 탭을 추가 제한하지 않는다.
- 외부 통계 페이지는 진입할 때마다 자체 접근 권한을 검증하는 기존 동작을 유지한다. 통계 탭 노출은 외부 서비스의 접근 권한을 부여하거나 조회 범위를 확대하는 의미가 아니다.
- 이번 P04-A에서 외부 통계 서비스의 권한 체계나 조회 범위를 변경하지 않는다.
